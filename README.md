# ReturnFour

Four-bar live return desk for bedroom producers and AI-music finishers.

After the bridge or the solo the chorus slams back cold. Session players write four live bars of return — walk back, kit rebuild, brass settle, bass land — so the unfinished song finally comes home earned, not hard-cut.

Live samples only. FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and the PreEight acoustic kit. Loaded from the public PreEight sample CDN. No oscillators. Audio never leaves the tab.

Yesterday’s ships were PickupTwo (two-bar doorway into the first chorus) and DieTwice / OffLoop / ThinFour. ReturnFour is the missing **homecoming** after the middle of the song so the hook re-enters like a band, not a loop.

## Distinct from the rest of the line

| Tool | Job |
| --- | --- |
| PickupTwo | Two bars of approach into the first chorus |
| TagFour / AfterHook / Exhale / EndEight / LastHook | After the last chorus |
| HoldFour / AirFour / ThinFour | Space, hold, or thinning before the next section |
| DieTwice | False ending — chorus dies and returns |
| PreEight / LiftTwo | Climb or production lift into the hook |
| ChorusTwo / UpStep | Second-chorus stack or last-chorus key change |
| BridgeFour / MidEight | The bridge itself |
| AuraMix / VocalForge / AuraStudio | Vocal chain |
| MixForge / RefPunch | Mix and reference |
| HookGrid / Sideman / ReleaseForge | Form, session, release |
| **ReturnFour** | Four bars of **live return** so the chorus comes home after the bridge or solo |

## Loop

1. Pick a groove (Amber Room, Porch Light, Fold Night).
2. Pick a return (walk-back, kit-rebuild, brass-settle, bass-land, piano-resolve, nylon-home, violin-bed, half-time, stop-then-home, full-return).
3. Hear the previous section loop without the doorway home.
4. Hear the full pass: four bars previous, four bars return, four bars chorus landing.
5. Copy the punch list and bounce a WAV of bars 5–8.
